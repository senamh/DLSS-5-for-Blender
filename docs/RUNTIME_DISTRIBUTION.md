# Runtime: получение и распространение

Актуально: 9 сентября 2026. Это технический разбор, не юридическая консультация.

## Короткий вывод

Публичный ZIP проекта **не содержит runtime**. Текущий проверенный на RTX 5070
комплект нельзя считать разрешённым для публичного распространения:

- `nvngx_dlssnr.dll` получен не из документированного публичного NVIDIA SDK-канала;
- локальная копия `310.8.SF.0` не имеет проверяемой Authenticode-подписи;
- `renodx-dlss5.addon64` — отдельный сторонний бинарник; лицензия RenoDX core
  автоматически не даёт права распространять этот файл;
- `nvngx.dll_blender.dll` и `dlss5nr_bridge.dll` также не подписаны; для публичного
  выпуска нужны воспроизводимая сборка из опубликованного исходника и notices;
- ReShade имеет BSD-3-Clause, но это не легализует остальные файлы комплекта.

SHA-256 подтверждает только совпадение с протестированной копией, а не автора,
безопасность, лицензию или право распространения.

## Что разрешает общая лицензия NVIDIA RTX SDK

Лицензия NVIDIA RTX SDK допускает объектный код SDK как часть приложения при
соблюдении условий: приложение должно иметь существенную дополнительную
функциональность, SDK нельзя распространять как самостоятельный продукт,
условия для пользователя должны защищать права NVIDIA. Но применимость общей
лицензии зависит от того, каким SDK и каналом был предоставлен конкретный файл.
Она не подтверждает происхождение community-circulated `nvngx_dlssnr.dll`.

Официальные ссылки:

- NVIDIA RTX SDKs License: https://developer.nvidia.com/gameworks/nvidia_rtx_sdks_license_12apr2021.pdf
- Streamline/DLSS integration: https://developer.nvidia.com/rtx/streamline/get-started
- ReShade BSD-3-Clause: https://github.com/crosire/reshade

## Разрешённый сейчас сценарий

Пользователь сам указывает локально полученный комплект, которым он вправе
пользоваться. Аддон проверяет только известные хеши и запускает его локально.
Публичная сборка не скачивает DLL с зеркал, из игр или сторонних архивов.

`package_addon.py --private-runtime` предназначен только для личного offline-
переноса уже имеющегося RenoDX-комплекта. Результат нельзя публиковать без
отдельного подтверждения прав на каждый бинарник. Native-комплект эта опция
не включает.

## Условие для полноценного установщика

Добавить runtime в публичный релиз можно после выполнения всех пунктов:

1. NVIDIA публикует DLSSNR через официальный SDK/репозиторий или письменно
   подтверждает распространение конкретной версии и файлов.
2. Для RenoDX DLSS5 add-on найдена его собственная лицензия с правом бинарного
   распространения либо используется наша реализация из воспроизводимого исходника.
3. Caller shim и bridge собираются из опубликованного исходника в CI.
4. В ZIP включены требуемые EULA, copyright и third-party notices.
5. CI проверяет происхождение, подпись и SHA-256 до упаковки.
6. Выпуск не называется официальным или одобренным NVIDIA.

До этого момента безопасная схема — addon-only ZIP плюс ручной локальный путь.
