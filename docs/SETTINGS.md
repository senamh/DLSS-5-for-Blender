# Управление аддоном 0.2.2

В Preferences → Дополнительно доступна «Постоянная сессия NR (эксперимент)».
По умолчанию выключена. Нужны отдельные Native Bridge DLL и NVIDIA NGX Runtime
из проверенного native-комплекта; пути RenoDX не заменяют эти зависимости.
После изменения backend остановите и заново запустите предпросмотр.
Для возврата выключите переключатель. Ошибка не вызывает скрытого переключения.
Natural и Default — режимы модели; FILM/STRONG — пресеты проекта, не настройки
из конкретных YouTube-роликов. Усиление может изменить черты лица и мелкие детали.

## Основная панель

3D Viewport → N → DLSS 5. Предпросмотр — в текущем viewport; итог — в отдельном Image Editor.

- «Сила эффекта» — NRIntensity, не процент смешивания с исходником.
- «Эффект во вьюпорте» / «Вернуться к сцене».
- «Рендер с эффектом…» — только сохранение файла с выбором папки/имени/формата.
- «Применить к готовому рендеру» — когда Render Result уже существует.
- «Показать результат» — отдельное окно Image Editor, повторное нажатие использует то же окно.
- «Сохранить…» — после обработки.
- Остановка NR — при активной обработке; обычный рендер отменяется Esc.

## Дополнительно

Пресеты «Мягкий», «Сброс / базовый», «Кино-тон», «Выразительный».
Это наборы параметров модели, не гарантия стилистики конкретного ролика.
Default и экспериментальный Natural; Cinematic выключен из-за наблюдавшихся сбоев.
Тон, структура, структура кожи (-1 = runtime default), автоматическая маска.
Базовые: Default, сила/тон/структура = 1, кожа = -1, automask выключен.
Сохранённые настройки пользователя автоматически не сбрасываются.

Флажок обработки после F12 относится к одному кадру и ручному последующему сохранению.
Рендер через F7/кнопку фиксирует настройки стиля и файла на момент запуска.
Оригинальный Render Result, камера, семплы и композитор не заменяются.

## Простые резервные клавиши

| Клавиша | Действие над 3D Viewport |
| --- | --- |
| F6 | Переключить предпросмотр |
| F7 | Открыть меню рендера в файл |
| F8 | Остановить NR / предпросмотр |
| N | Стандартная боковая панель Blender |
| F12 | Стандартный рендер Blender |
| Esc | Стандартная отмена рендера / диалога |

F6/F7/F8 проверены в стандартной раскладке Blender 5.2.1.
В старой Blender 2.7x, Industry Compatible или пользовательской раскладке назначения
могут отличаться: аддон ищет занятые клавиши и отключает только свои конфликтующие
назначения. Проверка повторяется кнопкой «Проверить установку и GPU».
Ни чужие привязки, ни стандартные N/F12/Esc не изменяются. F10 не используется.
Старые Ctrl+Alt+D/R/Esc больше не регистрируются.
F5/F8 старого экранного ReShade не являются управлением новым NR viewport.

## Вывод

Формат, каналы, глубина, сжатие/качество — Blender Output Settings.
Путь с `####` учитывает номер кадра; относительный путь требует сохранённого .blend.
Существующие файлы защищены от перезаписи. Подробнее: [совместимость](COMPATIBILITY.md).

## Прогресс и готовый кадр

Полоса NR показывает проценты этапов процесса: подготовка, запуск, подтверждение NR,
проверка результата. Это не точный процент вычислений NVIDIA: такого callback runtime не даёт.
100% появляется после публикации проверенного изображения. Таймером проценты не накручиваются.
При новом запросе сохраняется предыдущий кадр, пока вид/камера не изменились.
Уведомления depsgraph не отбрасывают завершённую обработку; одинаковый вход не запускает NR повторно.
