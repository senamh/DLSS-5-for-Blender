# Дорожная карта — 0.2.2

## Сделано

Текущий viewport, общие стили с рендером, меню сохранения только файла, защита файлов,
простые проверяемые клавиши, переносимые пути runtime, проверки официальных сцен.
Добавлена экспериментальная постоянная сессия; проверены два лица, матовые формы,
металл/стекло и официальные сцены до 1920 px. Это первые тесты, не сертификация качества.

## Не завершено / не обещано

1. Публичный полностью лицензированный установщик всех native-зависимостей.
2. Проверка конкретных RTX 50, затем отдельное исследование RTX 20/30/40/PRO runtime.
3. Дальнейшее сокращение захвата/передачи кадра и проверка постоянной сессии на других ПК.
4. Настоящие Cycles motion/depth guides и temporal history.
5. HDR/EXR, анимация/multiview с корректной временной обработкой.
6. Систематическое сравнение качества на материалах/персонажах и разных разрешениях.

Установка на произвольной ОС/видеокарте и игровой realtime не являются достигнутыми
целями. [Текущие ограничения](COMPATIBILITY.md).
