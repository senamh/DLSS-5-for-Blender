# Совместимость — 0.2.1, 9 сентября 2026

Установка Python-аддона и успешная NVIDIA Neural Rendering обработка — разные вещи.
Для текущего NR worker нужны **Windows x64, Direct3D 12, NVIDIA RTX, совместимый
драйвер и точный проверенный комплект runtime**. Тестовая ОС: Windows 11.
Blender: обычная версия 5.2.x; фактически проверена 5.2.1 LTS. Сборка Blender не нужна.

| Видеокарта / платформа | Статус именно этого аддона |
| --- | --- |
| GeForce RTX 5070 desktop | Проверено: viewport, итоговый кадр, официальные Blender demo scenes |
| Другие GeForce RTX 50, включая ноутбуки | Целевая серия; индивидуальные модели здесь не протестированы, успех требует проверки NR |
| RTX 40 / RTX 30 / RTX 20 | Для текущего закреплённого комплекта поддержка не подтверждена; не считать совместимыми |
| RTX PRO / Quadro | Не проверено; имя RTX не гарантирует доступность feature 18 |
| GTX, AMD Radeon, Intel Arc, Apple GPU, CPU-only | NR этим backend не поддерживается |
| Linux / macOS | NR worker не поддерживается; Windows EXE/DLL не запускаются |

[NVIDIA описывает официальный DLSS 5 для GeForce RTX 50 Series](https://research.nvidia.com/labs/adlr/DLSS5/).
Это не сертификация нашего аддона. [Merserk Visual Enhancer](https://github.com/Merserk/dlss5-visual-enhancer)
заявляет отдельные архитектурные runtime для RTX 20/30, 40, 50; эти варианты не
перенесены и не проверены здесь. Чужой список поддержки нельзя приписывать этому ZIP.
Защита SHA-256 намеренно отклоняет непроверенные DLL, включая альтернативные сборки.

## Драйвер и память

На тестовом RTX 5070 использовался драйвер 591.86. Это проверенная конфигурация,
**не установленная нами минимальная версия**. Для другого ПК рекомендуется актуальный
официальный NVIDIA-драйвер; окончательная проверка — успешный запуск NR.
Точный минимум VRAM для произвольной сцены не измерен. Cycles, текстуры и отдельный
NR worker одновременно занимают память. При нехватке памяти уменьшите сложность
сцены/выходное разрешение; не обещается 4K на любой карте серии.

## Форматы и пределы

- PNG, JPEG, TIFF, BMP, Targa, WebP; каналы/качество/сжатие — из Blender.
- Один кадр; каждая сторона от 96 до 4096 пикселей. Viewport ограничен 1280 по большей стороне.
- Внутренний NR — sRGB SDR RGBA8. PNG/TIFF 16-bit — контейнер, не восстановление HDR.
- EXR/HDR, анимация, multiview, Frame Generation, настоящий temporal history не поддержаны.
- Входы image-only: постоянная дальняя глубина, нулевое движение, сброс истории.
- Это экспериментальная обработка изображения, не полноценная нативная Cycles DLSS интеграция.
- Успех feature 18 и отличие пикселей не доказывают улучшение качества или совпадение с роликами.
