# Текущая архитектура — 0.2.2

Обычный Blender → Python-аддон → экспорт SDR снимка/Render Result →
изолированный D3D/NGX frame host → проверка feature 18 и целостности →
полный обработанный кадр во viewport или файл через Blender encoder.

- `viewport.py`: захват фактически отрисованного Cycles viewport без собственного overlay.
  GPUOffscreen не использован: в проверке он не предоставил фактическое Cycles изображение.
- `frame_job.py`: приватные проверенные копии DLL, новый каталог входов и новые логи на каждый кадр.
  В сеансе preview копии переиспользуются; подмена закешированных файлов отклоняется.
- `frame_result.py`: целостность входов, размер результата, exit code и явное
  `inline feature 18 evaluation succeeded`. Отличие пикселей не доказывает улучшение.
- `final_render.py`: снимок настроек при старте, один кадр, отмена своего worker.
- `final_render.create_job`: явный выбор backend из Preferences, RenoDX по умолчанию.
- `native_frame_job.py`: совместимый адаптер image-only SDR, приватные закреплённые DLL.
- `native_session.py` / `stock_worker.py`: постоянный отдельный Blender-процесс,
  один кадр в работе, атомарные файлы и проверенные квитанции. Сбой завершает сессию;
  автоматической подмены backend нет. История сбрасывается для каждого кадра.
- `output.py`: кодирование форматов Blender без второго AgX и без перезаписи файлов.
- `runtime_setup.py`: переносимые каталоги, диагностические сообщения; никакой загрузки DLL из сети.
- `shortcuts.py`: F6/F7/F8, пропуск конфликтов, снятие привязок при отключении аддона.

Текущие depth/motion — явные нейтральные placeholders; история сбрасывается.
Нет renderer-grounded temporal интеграции, HDR, анимации и Frame Generation.

`native/src` содержит реализацию экспериментального native bridge. `patches` и
старые stock/screen-injection scripts относятся к прежним экспериментам.
Сборка модифицированного Blender не требуется. Два backend используют разные
файлы NR-модели; результаты и телеметрия не должны считаться идентичными.
