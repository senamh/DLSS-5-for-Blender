# Проверки — 0.2.2, 2026-09-09

## Проверки 0.2.2

- 83 локальных unit tests; запуск GitHub CI для этих изменений ещё не подтверждён.
- Постоянный worker под Blender: повторный кадр, смена настроек, отмена, crash/restart,
  идентичный результат после восстановления, запрет устаревшей квитанции.
- GUI-тест через операторы Blender: фактический VIEW_3D draw, смена стиля/объекта,
  стабильный idle, вывод только файла, отдельный Image Editor без дубликата окна.
  Это автоматическая проверка, не ручные клики и не тест каждой раскладки клавиатуры.
- Установочный ZIP проверен в изолированной папке на том же RTX 5070: полный
  Cycles → native NR → PNG, alpha, снимок настроек, отмена, запрет перезаписи.
- Cozy Kitchen 1920×1808 и Panthera 1920×960: 64 семпла, сохранены одинаковые
  оригиналы/результаты. Сглаживание шерсти и изменение бликов видимы; улучшение не универсально.
- Простые формы/металл/стекло: BALANCED/STRONG; умеренные изменения светотени.
- Лица 1280×1280: Lee Perry-Smith (CC BY 3.0, источник three.js) и Male Head 3D Sculpt,
  diaverx miky (BlenderKit, royalty_free). Default/Natural/STRONG, два backend.
  Natural заметно меняет кожу/веки/губы; сохранность личности и точность не подтверждены.
  У Lee глаза закрыты; тест текстуры не охватывает радужку/зрачок.

Воспроизводимые скрипты: `smoke_addon_zip.py`, `smoke_native_final.py`,
`smoke_unified_viewport.py --native`, `quality_pairs.py`, `render_blenderkit_face.py`,
`render_head_benchmark.py`. Подробности разработки: [журнал](CYCLES_INTEGRATION_PROGRESS.md).
Локальные evidence и изображения на рабочем столе не означают публикацию в GitHub.

## Исторические проверки 0.2.0

Платформа реального GPU-теста: Windows 11 x64, Blender 5.2.1 LTS, RTX 5070.
Полный матричный тест других компьютеров/драйверов не выполнен.

## Проверено

- 59 unit tests: payload gate, lifecycle/cache, runtime discovery, неизвестные DLL,
  отсутствующий runtime, перенос каталогов, отказ на Linux/macOS.
- F6/F7/F8 через Blender event_simulate: переключение, остановка и диалог;
  стандартная раскладка без конфликтов. GPU callbacks изолированы в keyboard-тесте;
  сам NR проверен отдельно.
- Подставленная чужая F6 осталась активной, назначение DLSS отключилось; после
  удаления конфликта F6 восстановилась.
- Персональный ZIP распакован в новый каталог; старые environment/Preferences пути
  исключены. Реальный NR на официальном Kitchen 1008×950 завершился успешно.
  Это проверка переноса каталога на том же ПК, не тест произвольного другого GPU.
- Реальный NR во viewport на официальной Cozy Kitchen: обновление стиля и объекта,
  рендер в файл с тем же стилем, без добавления окна даже при старых NEW/BOTH ID properties.
- Экспорт PNG/JPEG/TIFF/BMP/Targa/WebP, alpha, 16-bit контейнер, неизменность color settings,
  запрет перезаписи, сохранение пути/формата, выбранных при старте.
- Один владелец меню/обработчиков, сохранение стиля в .blend, повторная регистрация.

## Официальные сцены

[Blender demo files](https://www.blender.org/download/demo-files/):

- Panthera Spelaea, Joanna Kobierska; полные credits внутри сцены, CC-BY — Blender 5.2 splash.

## Производительность

Cozy Kitchen payload 1008×950, одинаковый вход и полные diagnostics:
повторный worker 5,49 → 4,12 с; подготовка файлов 1,14 → 0,04 с.
Без времени Cycles, захвата viewport и debounce. Первый запуск всё ещё копирует/проверяет DLL.
Preview дополнительно не пишет ненужные before/after PNG.
При изменении только стиля ожидание 0,4 с, сцены/вида — 1,5 с.

Видеоролики пользователя не являются воспроизводимым эталоном этого теста.
Не заявляются realtime FPS, RTX 40 compatibility, HDR или полноценная DLSS 5 game integration.
