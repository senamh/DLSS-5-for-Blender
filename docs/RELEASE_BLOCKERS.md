# Ограничения выпуска 0.2.0

Текущий ZIP аддона готов для установки и экспериментов на проверенной конфигурации.
Публичный ZIP не включает proprietary runtime.

До универсального продукта остаются:
- права и воспроизводимый канал распространения всех native зависимостей;
- реальные тесты матрицы GPU/драйверов/ПК;
- полноценные renderer guides, история, HDR и анимация;
- доказательная оценка качества, а не только успешный feature 18.
