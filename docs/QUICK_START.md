# Установка 0.2.2 на другом ПК

## Экспериментальная постоянная сессия (0.2.2)

По умолчанию используется прежний RenoDX. Новый режим включается в настройках
аддона → «Дополнительно» → «Постоянная сессия NR (эксперимент)». Укажите
`Native Bridge DLL` и `NVIDIA NGX Runtime` из проверенного native-комплекта;
обычная папка RenoDX для этого режима не подходит. Проверка SHA256 обязательна.
Сам ZIP аддона не содержит этих DLL и не обеспечивает работу без runtime.

После изменения режима остановите и снова запустите эффект во вьюпорте.
Чтобы вернуться к RenoDX, выключите переключатель и перезапустите эффект.
Автоматического переключения при ошибке нет. Постоянная сессия ускоряет повторные
кадры предпросмотра; отдельные итоговые рендеры пока создают новую сессию.
Режим использует другой файл модели NVIDIA: одинаковое качество не гарантируется.
Только SDR, без временного накопления и подтверждённого HDR.

Проверено в фоновом Blender 5.2.1 на RTX 5070: Cycles → NR → PNG,
сохранение настроек и прозрачности, отмена и запрет перезаписи.
Также прошёл автоматический тест в обычном окне Blender: вывод во VIEW_3D,
смена стиля, обновление после изменения объекта, отсутствие обработки в покое,
рендер только в файл и отдельный Image Editor без дублирования окна.
Операторы запускались программно, ручные клики и другие GPU не проверялись.

## Перенос и зависимости

Сначала проверьте [совместимость](COMPATIBILITY.md). «Установился аддон» не означает,
что GPU может выполнить DLSS 5 NR. Подтверждённый тестовый GPU: RTX 5070.

## Вариант 1: персональный offline ZIP с runtime

Если вам передан персональный комплект `cycles_dlss5-0.2.1-private-offline.zip`
с уже имеющимися законно полученными зависимостями:

1. Установите обычный Blender 5.2.x на Windows x64 и подходящий NVIDIA-драйвер.
2. Edit → Preferences → Add-ons → Install from Disk → выберите ZIP без распаковки.
3. Включите Cycles DLSS 5. В его Preferences оставьте пути пустыми — комплект
   находится внутри аддона и определяется относительно места установки.
4. Нажмите «Проверить установку и GPU». Проверка хешей — только проверка файлов;
   фактическая совместимость подтверждается успешным запуском эффекта.
5. Откройте сцену, N → DLSS 5 → «Эффект во вьюпорте». Дождитесь обработки.
6. «Рендер с эффектом…» → выберите существующую папку, свободное имя и формат.

Если переносите свои Preferences со старого ПК, очистите прежние абсолютные
«Папка runtime» и «Frame Host» либо выберите новый каталог. Сам .blend переносит
стили, но не исполняемые зависимости. Не копируйте DLL рядом с blender.exe.

Персональный комплект предназначен для вашего offline-переноса при наличии прав
на использование компонентов. Он не опубликован в GitHub и не является разрешением
на распространение NVIDIA/ReShade/RenoDX бинарных файлов.

## Вариант 2: ZIP исходного аддона из GitHub

[Откройте упаковку аддона](https://github.com/senamh/DLSS-5-for-Blender/actions/workflows/addon-package.yml):
успешный запуск → Artifacts → cycles-dlss5-0.2.1-addon. Внешний ZIP GitHub нужно
распаковать, затем установить внутренний ZIP аддона через Install from Disk.
Можно собрать его самостоятельно: `python scripts/package_addon.py`.

Этот ZIP не включает runtime. В выбранной вами папке должны находиться:

```text
runtime/
  dlss5-feed-host64.exe
  opengl32.dll
  renodx-dlss5.addon64
  nvngx_dlss.dll
  nvngx_dlssnr.dll
```

Допускается host в подпапке `frame-host/`. Host — с адаптером `--frame` из этого
репозитория, не произвольный EXE Merserk/Feeder. [Workflow сборки host](../.github/workflows/upstream-frame-host.yml)
и [адаптер](../native/upstream_host/frame_mode.h) предназначены для разработчиков.
Runtime-файлы пользователь получает самостоятельно из разрешённого ему источника;
универсального проверенного публичного one-click установщика зависимостей сейчас нет.
Точные SHA-256 четырёх поддержанных runtime файлов находятся в
[`RUNTIMES`](../addon/cycles_dlss5/frame_job.py). Другие версии отклоняются,
а неизвестная поддержка GPU не считается подтверждённой.

Укажите каталог в Preferences → Cycles DLSS 5 → «Папка runtime».
Либо поместите комплект в `%LOCALAPPDATA%/DLSS-Blender/runtime`.
Также поддерживается `DLSS5_RUNTIME_DIR` перед запуском Blender.
Порядок: выбранный каталог; иначе environment, встроенный комплект, LOCALAPPDATA,
затем старые preview-каталоги для обратной совместимости.
Настройки не перезаписывают исходные DLL и не устанавливают ничего в системные папки.

## Сохранение и клавиши

F6 — предпросмотр; F7 — меню вывода в файл; F8 — остановить NR.
Клавиши действуют над 3D Viewport и пропускаются при обнаруженном конфликте.
Кнопки доступны независимо от раскладки. [Все настройки](SETTINGS.md).

PNG/JPEG/TIFF/BMP/Targa/WebP. Существующий файл не перезаписывается — выберите
новое имя. Для путей `//` сначала сохраните .blend. HDR/EXR и анимация не поддержаны.
«Показать результат» открывает отдельное окно Image Editor; 3D Viewport не меняется.
Нормальный F12 может запускать необязательный постпроцесс; это отдельная возможность,
не автоматическое сохранение с настройками меню F7.

## Если не работает

- Нет runtime: выберите папку/установите персональный полный ZIP.
- Непроверенная версия DLL: не отключайте контроль хеша, используйте проверенный комплект.
- Нет эффекта на другом GPU: проверьте совместимость, драйвер, память и сообщение NR.
- Нет изменений сразу: дождитесь Cycles и отдельного NR worker; это не realtime.
- Клавиша занята: Preferences → проверить; используйте кнопку либо собственную раскладку.
- Старый экранный ReShade: запустите обычный Blender без инжекции, иначе будет двойная обработка.
- После обновления сохраните проект и перезапустите Blender.
