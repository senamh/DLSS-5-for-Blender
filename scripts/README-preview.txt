DLSS addon 0.2.1 / обычный Blender 5.2.x
Актуальная инструкция: https://github.com/senamh/DLSS-5-for-Blender/blob/main/docs/QUICK_START.md
Совместимость: https://github.com/senamh/DLSS-5-for-Blender/blob/main/docs/COMPATIBILITY.md

Проверено: Windows 11, Blender 5.2.1, RTX 5070. Другие GPU не считать проверенными.
Панель N > DLSS 5. Предпросмотр — текущий viewport. Результат — отдельный Image Editor.
Рендер с эффектом — только файл, выбор папки/имени/формата Blender.
F6 — эффект, F7 — меню рендера, F8 — остановить NR. Курсор над viewport.
Занятые клавиши пропускаются. N/F12/Esc Blender не переназначаются, F10 не используется.
После смены раскладки: Preferences > Проверить установку и GPU.
Перезапустите Blender после обновления.

Runtime: выбранная папка, встроенный комплект либо LOCALAPPDATA/DLSS-Blender/runtime.
Публичный ZIP без proprietary DLL; персональный offline ZIP — только личный перенос.
NR — image-only, SDR8, не игровой realtime. Нет HDR/EXR, анимации и Frame Generation.
Прежняя экранная инжекция ReShade — архив, не текущий способ запуска.
