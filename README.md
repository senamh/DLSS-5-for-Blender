# DLSS 5 для Blender 

Экспериментальная NVIDIA Neural Rendering обработка в **обычном Blender 5.2**.
Актуально: **10 сентября 2026**.
Текущая версия: **0.2.2**, экспериментальная.

## Скачать и установить

### Требования

- Windows 11 x64.
- Blender **5.2.x**.
- NVIDIA RTX и актуальный драйвер. Фактически проверена RTX 5070;
  подробности — в [матрице совместимости](docs/COMPATIBILITY.md).
- Совместимый DLSS NR runtime, полученный пользователем отдельно из разрешённого источника.

### Установка аддона

1. Скачайте [релиз v0.2.2](https://github.com/senamh/DLSS-5-for-Blender/releases/tag/v0.2.2)
   или [готовый ZIP аддона](release/cycles_dlss5-0.2.2-public-safe.zip).
2. **Не распаковывайте ZIP.** Откройте Blender → **Edit → Preferences → Add-ons**.
3. Нажмите **Install from Disk**, выберите `cycles_dlss5-0.2.2-public-safe.zip`
   и включите **Cycles DLSS 5**.
4. Откройте настройки аддона и укажите **Папка runtime**. В ней должны находиться:

   ```text
   dlss5-feed-host64.exe
   opengl32.dll
   renodx-dlss5.addon64
   nvngx_dlss.dll
   nvngx_dlssnr.dll
   ```

5. Нажмите **Проверить установку и GPU**. Проверка должна подтвердить файлы runtime;
   фактическая совместимость подтверждается только успешной обработкой кадра.
6. Откройте сцену с **Cycles**, затем в 3D Viewport нажмите **N → DLSS 5**:
   **Эффект во вьюпорте** для предпросмотра или **Рендер с эффектом…** для вывода в файл.

Если аддон не видит runtime, снова выберите его папку в Preferences и перезапустите
Blender. Не копируйте DLL рядом с `blender.exe`. Подробная переносная установка и
диагностика: [Quick Start](docs/QUICK_START.md).

> **Важно:** публичный ZIP из GitHub не содержит proprietary runtime NVIDIA/RenoDX/
> ReShade и сам по себе не включает настоящее NR. Персональный offline ZIP с уже
> имеющимся runtime нельзя публиковать или продавать без прав на эти бинарные файлы.
> [Почему runtime распространяется отдельно](docs/RUNTIME_DISTRIBUTION.md).

[Настройки и клавиши](docs/SETTINGS.md) · [Проверки и ограничения](docs/TESTING_STATUS.md) · [Изменения](CHANGELOG.md)

## Что работает

- Эффект прямо в текущем 3D Viewport, без «до/после». Готовый рендер открывается отдельно в Image Editor.
- Асинхронное обновление после остановки движения; общие настройки NR для viewport и рендера.
- «Рендер с эффектом…» → **только файл**: выбор папки, имени, формата и параметров Blender.
- Камера, разрешение, процент разрешения, семплы и композитор берутся из сцены.
- Ручное применение к уже готовому Render Result без повторного рендера.
- Один интерфейс аддона; остановка обработки; защита существующих файлов от перезаписи.
- Проверка runtime/GPU и переносимые пути, без привязки к имени пользователя или Steam.
- Опциональная постоянная сессия NR: Preferences → Дополнительно. Другой закреплённый
  native runtime, проверка SHA256, отмена/перезапуск. По умолчанию выключена.

## Быстрые клавиши

Курсор над 3D Viewport, стандартная раскладка Blender 5.2:

| Клавиша | Действие |
| --- | --- |
| F6 | Эффект во вьюпорте: включить / выключить |
| F7 | Меню рендера с эффектом в файл |
| F8 | Остановить NR и предпросмотр |
| N | Стандартная боковая панель Blender |
| F12 / Esc | Стандартный рендер / его отмена, аддоном не переназначаются |

Если F6/F7/F8 заняты другой раскладкой или аддоном, конфликтующее назначение DLSS
отключается; используйте кнопку. Проверить повторно можно в Preferences кнопкой проверки.
Старые Ctrl+Alt+D/R/Esc удалены. F10 аддон не использует.

## Совместимость и честный статус

Проверено на **Windows 11, Blender 5.2.1 LTS, GeForce RTX 5070**.
Другие RTX 50 — целевая серия, но не протестированы по каждой модели.
RTX 20/30/40 и RTX PRO не подтверждены для нашего закреплённого runtime.
AMD/Intel/Apple/GTX и Linux/macOS не поддерживают этот NR backend.
Подробности и источники — в [матрице совместимости](docs/COMPATIBILITY.md).

Основной RenoDX-путь подтверждает вызов NVIDIA feature 18; экспериментальный
native-путь проверяет результат DLL и квитанцию конкретного кадра. Оба работают через
**image-only consumer**, а не полноценную нативную Cycles/game интеграцию:
нет настоящих motion/depth guides и temporal history. Это не Frame Generation
и не ускоритель самого Cycles. HDR/EXR, анимация, multiview не поддержаны.
Внутренняя точность — 8-bit sRGB SDR, даже при сохранении в 16-bit PNG/TIFF.
Совпадение качества с роликами и улучшение каждого кадра не гарантируются.

В тесте постоянной сессии под Blender на Cozy Kitchen 1008×950 первый ответ занял
3,235 с, повторный — 0,328 с. Это одиночный тест, **не FPS**, без рендера Cycles,
захвата viewport и первоначального копирования DLL.
На тестах лиц Natural заметно меняет кожу, глаза и губы. Это может выглядеть
реалистичнее, но не гарантирует сохранность исходных деталей или черт.
[Методика, тесты и ограничения](docs/TESTING_STATUS.md).
