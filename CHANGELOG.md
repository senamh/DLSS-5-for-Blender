# Changelog

## 0.2.2 — экспериментальный локальный выпуск

- Опциональная постоянная native-сессия для viewport; итоговый рендер использует
  тот же выбор backend и настройки, но отдельную сессию на каждый рендер.
- Проверенные приватные копии трёх native DLL, сверка PID/номера кадра/настроек/
  хешей; отмена и отказ от неподтверждённого результата.
- Исправлен выбор проверки runtime в запуске viewport, render и диагностике.
- Проверены Cycles → NR → файл, отмена, PNG/прочие SDR форматы, Image Editor,
  стабильность idle, обновление стиля/сцены и ZIP в изолированной папке.
- Сравнения официальных сцен до 1920 px, простых материалов и двух лиц.
  Natural меняет детали: совпадение с оригиналом/роликами не гарантируется.
- Синхронизированы имя CI artifact и зависимости тестов; упаковка проверяет
  версии манифеста/bl_info и синтаксис. Успех GitHub CI требует отдельного запуска.


## 0.2.1

- Завершённый NR кадр не отбрасывается при уведомлениях depsgraph; служебные обновления
  публикации подавляются, одинаковый вход повторно не обрабатывается.
- Процент выполненных этапов рядом с NR; это не внутренняя телеметрия вычислений NVIDIA.
- «Показать результат» открывает отдельный переиспользуемый Image Editor, не меняя viewport.
- Из подсказок панели убраны неиспользуемые F5/F10.
- 63 unit tests и стресс-тест на официальной Cozy Kitchen: публикация, стабильный idle,
  смена стиля/объекта, файл, отдельный Image Editor и его повторное использование.

## 0.2.0 — 2026-09-09

- Переносимые пути runtime: комплект внутри аддона, выбранная папка, переменная
  `DLSS5_RUNTIME_DIR`, `%LOCALAPPDATA%/DLSS-Blender/runtime`; старые установки обнаруживаются для совместимости.
- Проверка файлов и GPU в Preferences; понятная ошибка при отсутствии зависимостей.
- Простые F6/F7/F8, проверка занятых клавиш без замены чужих назначений.
- Актуальная русская документация, честная таблица GPU и отдельная упаковка аддона.
- Персональный offline-пакет может включать уже имеющийся runtime; он не публикуется в GitHub.

## 0.1.9

- Удалено создание дополнительного viewport; рендер через меню — только в файл.
- Повторное использование проверенных DLL в сеансе viewport; ускоренная реакция на стиль.
- Первый набор резервных сочетаний Ctrl+Alt+D/R/Esc (заменён в 0.2.0).

## 0.1.8

- Асинхронный NR в текущем VIEW_3D, общие стили с итоговым рендером.
- Экспорт форматов Blender, выбор папки, защита от перезаписи.
- Проверка на официальных Cozy Kitchen и Panthera Spelaea.

Предыдущие эксперименты с экранным ReShade и сборкой Blender сохранены как архив,
но не являются текущей инструкцией установки.
